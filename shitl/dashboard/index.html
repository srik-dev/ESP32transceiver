A board appears here by itself once it has joined the same network as this computer (it announces itself on UDP 8762). To put a new board on the network, plug it into USB and run
tools/shitltx_ctl.py --port /dev/cu.usbmodemXXXX wifi <ssid> '<password>'
If announcements are blocked on your network, add the board by its IP address above.
